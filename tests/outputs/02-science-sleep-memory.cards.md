### 卡片 1：睡眠在记忆巩固中扮演核心角色
- **核心知识**：学习后被记住的内容是先以不稳定形式暂存，再在睡眠中通过反复“重放”转移到更稳定的长期记忆。
- **简明解释**：人学习新知识后，大脑并不会立刻永久保存，而是先以不稳定形式暂存，随后在睡眠中逐步转移到长期记忆。
- **例子 / 自测问题**：大脑会把新学的内容立刻永久保存吗？（不会，先以不稳定形式暂存，再在睡眠中逐步巩固）

### 卡片 2：慢波睡眠负责把临时记忆写入长期存储
- **核心知识**：慢波（深度）睡眠期间，海马体快速“重放”白天的神经活动并与新皮层交换信息，这是写入长期记忆的关键。
- **简明解释**：慢波睡眠期间，海马体会以更快的速度重放白天经历的神经活动模式，并与新皮层进行信息交换；这种重放被认为是把临时记忆写入长期存储的关键。
- **例子 / 自测问题**：与长期记忆写入关系最密切的是哪个睡眠阶段？（慢波睡眠／深度睡眠）

### 卡片 3：REM 睡眠与情绪记忆和创造性联想有关
- **核心知识**：快速眼动睡眠（REM）更多与情绪记忆的处理和创造性联想有关。
- **简明解释**：REM 睡眠被认为有助于把新信息与已有知识建立联系，其作用方向与慢波睡眠不同。
- **例子 / 自测问题**：REM 睡眠更可能与哪类记忆处理相关？（情绪记忆的处理与创造性联想）

### 卡片 4：睡眠不足会明显削弱记忆
- **核心知识**：睡眠不足会明显削弱记忆，睡眠被剥夺者的回忆表现更差。
- **简明解释**：实验显示，与正常睡眠相比，睡眠被剥夺的受试者在回忆先前学习内容时表现更差。
- **例子 / 自测问题**：睡眠被剥夺的受试者在回忆先前学习内容时表现如何？（表现更差）

### 卡片 5：睡眠依赖的记忆巩固
- **核心知识**：学习后立刻睡觉的人，往往比学习后保持清醒的人记得更牢。
- **简明解释**：这一现象被称为“睡眠依赖的记忆巩固”，说明睡眠本身参与了记忆的稳定过程。
- **例子 / 自测问题**：学习后马上睡觉和保持清醒相比，哪种情况记得更牢？（学习后马上睡觉记得更牢）

### 卡片 6：小睡也能巩固记忆，并可据此安排学习
- **核心知识**：记忆巩固不只在夜里发生，白天短暂小睡也能带来类似效果。
- **简明解释**：白天 20~90 分钟的小睡也能带来类似的巩固效果，因此把学习安排在睡前、或学习后进行小睡，都是利用这一机制的有效策略。
- **例子 / 自测问题**：除了夜间睡眠，还有什么做法也能帮助巩固记忆？（白天 20~90 分钟的小睡）
