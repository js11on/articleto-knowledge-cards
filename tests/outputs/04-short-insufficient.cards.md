### 卡片 1：API 是什么
- **核心知识**：API（应用程序编程接口）是一组规则，让不同的软件之间可以互相通信。
- **简明解释**：API 让一个软件可以调用另一个软件的能力，例如天气应用通过 API 向气象服务请求数据。
- **例子 / 自测问题**：API 的全称是什么？（应用程序编程接口）

### 卡片 2：API 的作用是让开发者复用能力、实现解耦
- **核心知识**：使用 API 时，调用方不需要知道对方内部是如何实现的。
- **简明解释**：借助 API，天气应用无需了解气象服务的内部实现即可获取数据，开发者也不必从零构建所有功能。
- **例子 / 自测问题**：调用方通过 API 获取数据时，需要知道对方的内部实现吗？（不需要）
